5. LoRA Adapters (Coming Soon)

Fietsbel supports dynamic loading of LoRA adapters for task-specific fine-tuning. Custom Granite 4 adapters will be published once trained.

What are LoRAs?

Low-Rank Adaptation (LoRA) allows efficient fine-tuning of models for specific domains without retraining the entire model. Think of them as "plugins" or "party hats" for AI models.

Find Suitable LoRA for Your Use Case

Search the LoRA taxonomy to find the best adapter for your specific task:

Example command: {use case description} /find_suitable_lora #lora-taxonomy

Deterministic Multi-LoRA Pipeline

Instead of having an AI "choose" which adapter to use, Fietsbel uses structured workflows (n8n/PDL-style) where each step explicitly declares which LoRA to load.

{
  "pipeline": [
    {"lora": "medical", "task": "extract diagnoses"},
    {"lora": "legal", "task": "identify coverage"},
    {"lora": "financial", "task": "estimate cost"}
  ]
}

7. What Edge AI Can't Do (Yet)

Honesty about limitations builds trust. Here's what small models struggle with:

Complex Reasoning Failures

Ask: "If a train leaves at 2pm going 60mph for 3 hours, and another leaves at 3pm going 80mph, when do they meet?"

350M will likely fail. 3B might get it right with chain-of-thought prompting.

Context Length Limits

Granite hybrid models support as much tokens as you have RAM, but dense versions (those can have LoRA) are limited, depending on variant. Very long documents need chunking strategies (RAG).

Hallucinations

Ask: "When did Napoleon visit America?"

Models will confidently generate false information. Always verify facts against sources.

Creative Writing Quality

Small models (≤3B) produce functional but rarely beautiful prose. For creative work, larger models may be better.

Command Syntax (CLI-style orchestration)

For prototyping workflows. Production apps use visual UIs.

Syntax:
  /template   — Load prompt template
  #corpus     — Reference knowledge base
  @model      — Select model
  @model+lora — Model with LoRA adapter
  |           — Pipeline operator
  [Variable]  — Store output

Examples:
  /classify @granite350m input.txt
  
  @docling file.pdf | /extract | @granite3b+18 /compare #official
  
  [Doc] @docling privacy-policy.pdf
  /assess-privacy @granite3b+18 for #gdpr-official [Doc]
